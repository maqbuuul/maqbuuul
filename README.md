Important

theSVG exposes a CDN URL on each icon page; the URLs in this file use the package CDN form shown by theSVG, e.g. https://cdn.jsdelivr.net/npm/@thesvg/icons/icons/<slug>.svg.

Before publishing a huge icon wall, keep only tools you actually use. A focused 20–40 icon stack usually looks stronger than a catalog of every technology in the data ecosystem.
